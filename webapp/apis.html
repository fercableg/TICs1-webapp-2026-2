APIs

Endpoints del backend (Supabase / PostgREST) y código listo para el ESP32.

Cómo conectarse

Toda la red de la interfaz pasa por apiClient.js. Para apuntar al backend real, pon CONFIG.USE_MOCK_DATA = false y rellena API_BASE_URL y SUPABASE_ANON_KEY en config.js.

La anon-key de Supabase es pública por diseño; el control de acceso fino se hace con políticas de fila (RLS).
