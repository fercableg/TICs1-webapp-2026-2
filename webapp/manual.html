Manual de usuario

Guía paso a paso para cuidadores y familiares.

1. Cómo funciona el sistema ▾

La capa inteligente se instala sobre un colchón antiescaras existente y mide presión, temperatura y humedad en la superficie de contacto.

Un microcontrolador ESP32 adquiere las mediciones y las envía por Wi-Fi a esta interfaz, donde puedes consultarlas en tiempo real.

Sensores → ESP32 → Wi-Fi → Servidor → Interfaz web
2. Distribución de sensores ▾
  • Occipital (p1) — parte posterior de la cabeza.
  • Escápula izquierda (p2) y derecha (p3) — omóplatos, para detectar giros laterales.
  • Sacro (p4) — zona sacra, la más relevante para la prevención.
  • Talón izquierdo (p5) y derecho (p6) — talones, para detectar giros laterales.
  • Un sensor de temperatura y humedad (AHT20) ubicado al centro.

Los valores se muestran como lecturas relativas (0–4095), no como presión clínica.

3. Definición de alertas ▾
  • Crítica — dispositivo desconectado o condición que requiere revisión inmediata.
  • Advertencia — tiempo máximo en la misma posición o variación de temperatura.
  • Informativa — eventos de registro (cambio de posición, cama vacía).

Umbrales de referencia del firmware:

  • Confirmación de postura: 10 min.
  • Alerta por tiempo: 120 min.
  • Variación de temperatura: ±1.5 °C.
  • Cama vacía: suma de presión < 300.
4. Pasos operativos ▾
  1. Inicia sesión con tu cuenta (cuidador o administrador).
  2. Selecciona el dispositivo (colchón) que quieres supervisar.
  3. Revisa el Panel para ver postura, temperatura y humedad actuales.
  4. En «Monitoreo» observa el mapa de presión por zona.
  5. En «Alertas» confirma (ACK) las alertas que ya revisaste.
  6. En «Posiciones» registra manualmente un cambio de postura si corresponde.
  7. Si eres administrador, ajusta umbrales en «Monitoreo» o en «Ajustes».
5. Solución de problemas ▾
  • «Sin conexión» — verifica que el ESP32 esté encendido y con Wi-Fi disponible. La interfaz reintenta automáticamente.
  • «Cama vacía» — la presión total está bajo el umbral; revisa que la persona esté sobre el colchón.
  • Valores «—» — lectura fuera de rango o no disponible; espera la siguiente muestra.
  • Alerta no se actualiza — confirma (ACK) y espera el siguiente ciclo de sondeo.
